Automatische Quellenangaben

Dieses Bookmarklet erzeugt aus der aktuellen Artikelseite eine kompakte Quellenangabe, setzt sie automatisch in ein <p>...</p>-Element und kopiert das Ergebnis direkt in die Zwischenablage.

Ziehe diesen Button in deine Lesezeichenleiste:

Quellenangabe

Alternativ: Rechtsklick auf den Button → Link als Lesezeichen speichern

So funktioniert’s

  1. Blende die Lesezeichenleiste deines Browsers ein.
  2. Ziehe den Button „Quellenangabe“ per Drag-and-drop in die Leiste.
  3. Öffne anschließend eine Artikelseite, etwa bei einem Verlag, Journal oder arXiv.
  4. Klicke auf das gespeicherte Lesezeichen.
  5. Die formatierte Quellenangabe wird als HTML-Absatz direkt in die Zwischenablage kopiert.

Ausgabeformat

Das Bookmarklet gibt die Quelle mit Absatzmarke aus, zum Beispiel:

<p>Muster, M., Journalname, 2026</p>

Falls der Browser das direkte Kopieren blockiert, zeigt das Bookmarklet stattdessen ein Feld an, aus dem der Text manuell kopiert werden kann.
